# Project language

- Use English for all project-authored instructions, documentation, reports, code comments, CLI messages, figure labels, filenames, and commit messages.
- Apply the same English-only requirement to local deliverables created outside this checkout and to replies about this project.
- When updating an existing deliverable, translate any Chinese prose and rename Chinese-language filenames; update references and checksum manifests accordingly.
- Preserve original research data and third-party source material verbatim for provenance.
- Use inline code for short variables and single-line assignments; do not put them in fenced code blocks.
